
# 🧠 Python ML Sentiment Analysis Project

This is a simple Machine Learning project built using Python to classify the sentiment of a given sentence as **positive** or **negative**.

---

## ✅ Features

* Classifies sentences into **positive** or **negative** sentiment.
* Simple command-line interface for user interaction.
* Lightweight and easy to run locally.
* Uses pre-trained or custom ML model (as defined in `ai_model.py`).

---

## 📁 Project Setup

### **1. Clone the Repository**

```bash
git clone https://github.com/thushan-123/python-ML
cd python-ML-project
```

### **2. Create and Activate Virtual Environment**

```bash
python -m venv .venv
```

* **Windows**

  ```bash
  .venv\Scripts\activate
  ```
* **Linux / macOS**

  ```bash
  source .venv/bin/activate
  ```

### **3. Install Dependencies**

```bash
pip install -r requirements.txt
```

---

## 🚀 Run the Project

Once all dependencies are installed, run the model:

```bash
python ai_model.py
```

### 📌 Example Interaction

```
Enter a sentence : hate this
Result : negative

Enter a sentence :  wow intersting
Result : positive
```
